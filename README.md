📬 Appicarta

Appicarta is my final school project, developed as part of my professional course in Programming and IT.

The main goal of Appicarta is to modernize the traditional mailbox experience by integrating hardware and software into a smart, connected system. The application notifies users in real time whenever new mail is detected, reducing uncertainty and improving convenience in daily life.

🚀 Overview

In today's digital world, physical mail remains an important communication channel. However, it lacks the immediacy and interactivity that users are used to.

Appicarta bridges this gap by combining:

📡 IoT hardware (mailbox detection system)
📱 Mobile application
🌐 Web platform
⚙️ Backend API

This creates a seamless ecosystem where users can monitor and manage their mailbox remotely.

🧠 Key Features
📬 Real-time mail detection
Detects when new mail is placed in the mailbox.
🔔 Instant notifications
Users receive alerts directly on their mobile device.
👨‍👩‍👧‍👦 Family sharing system (Arco Familiar)
Allows multiple users to be connected and manage the same mailbox.
💬 Messaging between members
Users can communicate within their family group to coordinate mail collection.
🌍 Web presence
Informational website to present and promote the project.
🏗️ Project Structure

The repository is organized into three main parts:

🌐 /site

A React-based website designed to present and promote Appicarta.

Includes:

Project presentation
Feature highlights
Visual design focused on user engagement
📱 /FE (Frontend)

Mobile application built with React Native.

Responsible for:

User interface
Notifications
Interaction with backend services
Family system and messaging features
⚙️ /BE (Backend)

Backend developed in Node.js.

Handles:

API endpoints
User authentication
Data management
Communication between frontend and hardware system
🛠️ Technologies Used
Frontend (Mobile): React Native
Frontend (Web): React
Backend: Node.js
Hardware Integration: Arduino / ESP32 (mail detection system)
Networking: HTTP / REST APIs
